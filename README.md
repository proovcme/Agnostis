# Agnostis

Agnostis — рабочая концепция AI-платформы для разработки, проверки, публикации и поиска семейств Autodesk Revit.

Текущий фокус:

- веб-пространство для заданий, исходников, ФОП/shared parameters, стандартов, спецификаций и внутреннего каталога семейств;
- Revit-плагин как исполнительная среда, которая получает формализованное задание, помогает применить параметры и типы, проверяет открытое семейство и отправляет результат обратно;
- AI-слой для разбора ТЗ, сопоставления с ФОП, подготовки спецификации, проверки и генерации карточки каталога.

# MyVeras - AI Rendering Plugin for Revit

Плагин для Revit с гибридным движком генерации изображений на основе ИИ. Поддерживает локальную и облачную обработку с использованием паттерна "Стратегия".

## Архитектура

### Паттерн "Стратегия"
- **IRenderingEngine** - абстрактный интерфейс для движков рендеринга
- **LocalEngine** - локальный движок (ComfyUI/Automatic1111)
- **CloudEngine** - облачный движок (внешний REST API)

### Структура проекта
```
MyVeras/
├── MyVeras.Core/           # Основная логика и интерфейсы
├── MyVeras.Engines/        # Реализации движков рендеринга
├── MyVeras.Models/         # Модели данных
├── MyVeras.Settings/       # Управление настройками
├── MyVeras.UI/            # WPF интерфейс
├── MyVeras.RevitAPI/      # Интеграция с Revit
└── MyVeras.sln            # Решение Visual Studio
```

## Основные компоненты

### 1. Интерфейс рендеринга (IRenderingEngine)
- Асинхронное выполнение рендеринга
- События прогресса и завершения
- Отмена операций
- Проверка доступности

### 2. WPF интерфейс
- **Source Toggle**: Переключатель между локальным и облачным движком
- **Connection Status**: Индикатор подключения
- **Image Settings**: Промпт, разрешение, влияние ИИ, шаги
- **Gallery**: Галерея последних 3 рендеров
- **Prompt Helper**: Автоматический сбор контекста из модели

### 3. BIM Data Capture
- Скриншот активного вида Revit
- Карта глубины для ControlNet
- Сбор материалов и категорий элементов
- Формирование контекстного промпта

### 4. Настройки (Settings.json)
```json
{
  "ActiveProvider": "Local",
  "Cloud": {
    "Url": "https://api.provider.com/v1",
    "Key": "xxx"
  },
  "Local": {
    "Url": "http://localhost:7860",
    "Model": "SDXL_Architectural"
  }
}
```

## Установка и использование

### Требования
- Revit 2023+
- .NET Framework 4.8
- Windows 10/11

### Установка
1. Собрать проект в Visual Studio
2. Скопировать .addin файл в папку Revit Addins
3. Запустить Revit

### Использование
1. Открыть вкладку "MyVeras" в Revit
2. Выбрать источник (локальный/облачный)
3. Настроить параметры рендеринга
4. Нажать "Рендер"

## Локальный движок
- **URL**: http://localhost:7860 (ComfyUI/Automatic1111)
- **Модель**: SDXL_Architectural
- **ControlNet**: Depth map для архитектурной точности

## Облачный движок
- **URL**: https://api.provider.com/v1
- **Авторизация**: Bearer Token
- **Асинхронная обработка**: Job-based система
