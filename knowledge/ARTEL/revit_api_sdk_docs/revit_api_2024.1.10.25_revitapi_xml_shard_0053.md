### `P:Autodesk.Revit.DB.Events.RevitEventArgs.Cancellable`

Member kind: property
Symbol: `Autodesk.Revit.DB.Events.RevitEventArgs.Cancellable`

#### Summary

Indicates whether an event may be cancelled by an event delegate.

#### Remarks

If 'Cancellable' is true, event delegates may cancel the command that
was announced by the event. To do so, a delegate would set the 'Cancel' property to True.
Typically, post-events (e.g. DocumentPrinted) are not cancellable,
while most pre-events (e.g. DocumentPrinting) are cancellable, except for special
conditions and situations, such as when the Revit application is being closed
or if an event is raised during another event.

is the cross product of X and Y. Distances in the projection space are the same as
would be measured on paper if the view is printed without additional scaling.

Most views will return just one `T:Autodesk.Revit.DB.TransformWithBoundary` . The exceptions are
views with split crop regions. Split crop regions can be independently moved and therefore
each region of a split crop gets its own transform and boundary. You can check if a view has split crop
regions by getting the `T:Autodesk.Revit.DB.ViewCropRegionShapeManager` and calling `!:ViewCropRegionShapeManager.IsSplit()` .

When the view's crop region is split, many TransformWithBoundary objects will be returned.
Each TransformWithBoundary corresponds to one region of the split crop. To determine which
TransformWithBoundary to use when converting a model point into view projection space,
first test to see which split crop region boundary contains the model point.
See `!:TransformWithBoundary.GetBoundary()` .

#### Returns

The transformations from the model space to view projection space.

#### Exception `T:Autodesk.Revit.Exceptions.InvalidOperationException`

The view does not return transforms.
-or-
The view is a perspective view.

An unset BoundingBoxUV has its lower-left corner to the right of (and above)
